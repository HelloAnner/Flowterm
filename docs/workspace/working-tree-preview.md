# 工作区预览

## 目标

左侧文件树点击任意文件后，中间面板都展示当前工作区文件的只读预览。

这个预览只有一个模式，不再区分“实时”与“Git”：

- 文件有未提交改动时，使用统一 diff 风格渲染
- 文件没有未提交改动时，展示完整文本内容
- 图片文件展示原图预览，不走文本渲染
- 文件发生本地改动后，当前选中文件的预览自动刷新

## 设计原则

- 单一真相源：文件树状态和预览都基于当前工作区
- 按需计算：只为当前选中文件生成预览，不全量生成所有文件 diff
- 温和反馈：保留 Git 状态与实时活动提示，但不暴露双模式切换
- 只读可信：预览展示当前文件状态，不承担编辑职责

## 交互

### 文件树

- 点击任意文件，立即切换当前预览
- 选中态固定在当前文件
- Git 状态徽记继续保留
- 实时活动继续通过细竖线提示

### 预览面板

- 顶部展示相对路径与状态摘要
- 已改动文件展示 unified diff 风格内容
- 未改动文件展示带行号的全文预览
- 图片文件展示居中原图预览
- 当前文件预览刷新时不清空整个面板，避免闪烁

## 性能策略

- 项目刷新只重算文件树元数据，不重算所有文件 diff
- 文件预览改为按需读取
- watcher 事件到来后，只刷新活动项目快照与当前选中文件预览
- 预览渲染保持只读纯文本，不做前端 diff 计算
- 文本预览采用固定行高虚拟滚动，几千行文件只渲染视口附近的行
