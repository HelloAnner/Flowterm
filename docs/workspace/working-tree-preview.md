# 工作区预览

## 目标

左侧文件树点击任意文件后，中间面板都展示当前工作区文件的预览；其中 Markdown 文件支持轻量编辑。

这个预览只有一个模式，不再区分“实时”与“Git”：

- 文件有未提交改动时，默认使用统一 diff 风格渲染
- Markdown 文件例外，默认直接渲染当前工作区里的最新全文
- 文件没有未提交改动时，展示完整文本内容
- 图片文件展示原图预览，不走文本渲染
- 文件发生本地改动后，当前选中文件的预览自动刷新

## 设计原则

- 单一真相源：文件树状态和预览都基于当前工作区
- 按需计算：只为当前选中文件生成预览，不全量生成所有文件 diff
- 温和反馈：保留 Git 状态与实时活动提示，但不暴露双模式切换
- 可信可控：预览默认保持只读，只有 Markdown 在当前面板内承担轻量编辑与保存职责

## 交互

### 文件树

- 点击任意文件，立即切换当前预览
- 选中态固定在当前文件
- 常见文件类型显示专属图标，参考 JetBrains 的分类识别方式；未知类型回退通用文件图标
- Git 状态徽记继续保留
- 项目根目录不是 Git 仓库时，若内部子目录存在 Git 仓库，也要继续汇总这些子仓库的状态徽记与预览 diff
- 实时活动继续通过细竖线提示
- 干净的图片资源默认不进入文件树，避免静态素材淹没代码上下文

### 预览面板

- 顶部展示相对路径与状态摘要
- 顶部补充当前文件识别出的语言标签，明确预览语义
- 已改动文件展示 unified diff 风格内容
- 已改动的 Markdown 文件直接展示当前全文编辑器
- 未改动文件展示带行号的全文预览，并按文件类型做语法高亮
- 图片文件展示居中原图预览
- Markdown 文件使用原生文本编辑器展示完整源码，支持局部复制原始 Markdown、`cmd+a` 全选和显式保存
- 当前文件预览刷新时不清空整个面板，避免闪烁

## 高亮策略

- 语言识别基于文件名与扩展名双层映射，覆盖代码、脚本、配置和数据文件
- 常见入口文件优先按语义识别，例如 `Dockerfile`、`Makefile`、`.gitignore`、`.env*`
- 未识别文件回退为 Plain Text，保持可读性但不伪造语言
- 高亮主题使用暖色、低对比的语义分层：
  - keyword 偏琥珀
  - string 偏鼠尾草绿
  - function / tag 偏冷光蓝
  - comment 降低饱和度并保留一点斜体感
- diff 行背景与语法高亮叠加时优先保证行级状态可读，不让 token 颜色盖过新增/删除语义

## 性能策略

- 项目刷新只重算文件树元数据，不重算所有文件 diff
- 文件预览改为按需读取
- watcher 事件按短窗口合并后再派发，只刷新活动项目快照与当前受影响的选中文件预览
- watcher 默认忽略 `node_modules`、`dist`、`target`、`.vite`、`.turbo`、`.next` 等开发期产物目录
- 预览渲染对非 Markdown 文件保持只读纯文本，不做前端 diff 计算
- 文本与 diff 预览都采用固定行高虚拟滚动，只渲染视口附近与少量 overscan 行
- 干净文本仍按窗口向后端请求分块；大 diff 先在前端按可见范围切片渲染，避免一次挂载整段 DOM
