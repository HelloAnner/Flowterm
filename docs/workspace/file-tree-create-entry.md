# 文件树新建条目

## 目标

让左侧 Explorer 具备接近 VS Code 的基础新建能力：

- 在文件树根级新建文件
- 在文件树根级新建文件夹
- 右键文件树空白区、文件夹节点、文件节点时弹出菜单
- 支持在目标目录下新建子文件和子文件夹
- 新建时直接进入内联输入态，`Enter` 确认，`Esc` 取消

## 交互约束

### 入口

- Explorer 标题栏提供根级 `新建文件`、`新建文件夹` 快捷入口
- 文件树空白区右键，菜单至少包含：
  - `New File`
  - `New Folder`
- 文件夹节点右键，菜单至少包含：
  - `New File`
  - `New Folder`
- 文件节点右键，菜单中的新建行为默认落到该文件所在目录，等价于 VS Code 在当前上下文目录下创建同级条目

### 内联创建

- 触发新建后，不弹系统对话框，直接在文件树内插入一条输入行
- 在根级新建时，输入行插入根列表
- 在文件夹下新建时：
  - 若文件夹当前折叠，先自动展开
  - 输入行插入到该文件夹的子级区域
- 占位文案：
  - 文件：`New File`
  - 文件夹：`New Folder`
- 键盘行为：
  - `Enter`：提交创建
  - `Esc`：取消创建
  - `Blur`：若未提交，按取消处理，避免残留空输入框

### 创建完成

- 新建文件成功后：
  - 立即刷新文件树
  - 自动选中新建文件
  - 中间预览面板切到该文件
- 新建文件夹成功后：
  - 立即刷新文件树
  - 保持新建文件夹所在分支展开
- 如果输入名包含 `/`，允许一次创建多级子路径；其父目录按需自动补齐，行为与 VS Code 接近

## 路径与安全约束

- 所有创建路径都必须相对项目根目录
- 禁止绝对路径、`..`、盘符前缀等逃逸项目根目录的写法
- 新建文件时允许自动创建缺失的父目录
- 新建文件夹时使用递归创建目录
- 若目标已存在，直接返回温和错误，不覆盖现有文件或目录

## 前后端边界

新增 Tauri 命令：

- `create_project_entry(projectId, path, kind)`

参数约束：

- `path`：相对项目根目录路径
- `kind`：`file` 或 `folder`

返回值：

- 返回实际创建的相对路径，供前端更新选中态与刷新范围

前端 store 负责：

- 组合目标目录与输入名，生成相对路径
- 在创建子条目前确保父目录展开
- 新建文件后切换选中路径
- 调用项目刷新链路，复用既有快照与预览更新逻辑

## 错误反馈

- 名称为空时，不发起后端请求
- 路径非法或目标已存在时，在底部错误条显示简洁错误
- 创建失败不清空当前文件选中态
- 创建失败后，保留文件树的上下文，不做整页闪烁

## 验证重点

- 根级右键可以新建文件与文件夹
- 文件夹右键可以新建子文件与子文件夹
- 文件右键新建时，条目创建在其所在目录
- 折叠文件夹下新建时会先展开，再显示输入行
- 新建文件后会被自动选中并触发预览加载
- 新建文件夹后分支保持展开
- `Esc`、空名称、重名、非法路径都不会产生脏数据
