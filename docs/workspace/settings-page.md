# Settings Page

## 目标

为 Flowterm 增加一个类似 VS Code 的设置入口：

- 左侧工作区窄边栏底部提供固定的“设置”按钮
- 点击后，主工作区切换为独立设置页
- 设置页内部再使用一层分类边栏组织不同配置

这样用户可以在不离开当前工作台语境的前提下，找到主题、工作区信息和常用配置入口。

## 入口结构

### 外层边栏

- 位置：工作区最左侧窄边栏底部
- 形态：与“文件树”同级的图标按钮
- 行为：
  - 选中文件树时，继续显示原来的文件树 + Diff + 终端三栏布局
  - 选中设置时，保留左侧工作区边栏，右侧整体切换成设置页

## 设置页布局

设置页采用双栏：

- 左栏：设置分类导航
- 右栏：当前分类的详细内容

当前分类包括：

- `外观`
  - 主题选择
  - 深色 / 浅色分组
  - 选择后立即应用到界面、代码预览和终端
  - 终端排版参数：`字号 / 行高 / 字间距`
- `工作区`
  - 当前项目名、路径、文件数、改动数
  - 当前终端状态
  - 打开项目入口
- `快捷键`
  - 当前已支持的核心快捷操作说明
- `关于`
  - Flowterm 的工作台定位与当前状态摘要

## 设计原则

- 保持暖色、安静、低打扰的界面气质
- 不引入假的复杂配置系统；优先暴露当前已经真实存在的能力
- 设置页是“理解系统”和“调整环境”的空间，不是仪表盘
- 如果是终端密度问题，优先从 `xterm` 的 `fontSize`、`lineHeight`、`letterSpacing` 修正，而不是改外围布局

## 实现约束

- 复用已有主题系统，不新增平行配置源
- 终端排版偏好使用本地持久化，保持跨项目一致
- 不修改已有文件树交互，仅新增设置视图入口
- 设置视图与普通工作区布局分开存储拖拽比例，避免互相污染
