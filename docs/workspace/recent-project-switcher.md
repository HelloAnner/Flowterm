# 最近项目切换器

## 目标

在不打断当前工作流的前提下，让多项目切换更接近“抬手即达”：

- 顶部右侧提供最近项目入口
- 点击后展示最近激活过的项目列表
- 选择项目后立即切到该项目，并让顶部 Tab 保持相同的最近顺序
- 提供 `⌘ + ←` / `⌘ + →` 在最近项目之间循环切换

## 数据来源

- 项目基础列表仍来自 `useWorkspaceStore().projects`
- 最近顺序由前端维护，按项目激活时间排序
- 最近顺序持久化到浏览器 `localStorage`
- 后端 SQLite 继续只负责项目注册与当前激活项目，不新增表结构

## 交互约束

- 顶部项目标签采用浏览器式固定 Tab 设计，激活项目只切换状态，不改变标签顺序
- 顶部项目标签支持拖拽排序，并持久化为用户自己的固定顺序
- 拖拽过程中显示插入位置指示线，帮助判断落点
- 最近项目按钮位于顶部 Tab 栏右侧、添加项目按钮左侧
- 菜单打开后自动聚焦搜索框，可按项目名或路径过滤
- 列表项同时展示项目名与路径，当前项目显示当前态标识
- 选择列表项后关闭菜单并切换项目
- 切换时顶部 Tab 立即进入新项目态，工作区数据允许在切换后后台补齐
- 已访问过的项目优先复用本地快照与文件预览缓存，再在后台静默刷新
- 已在内存中完成水合的项目，回切时优先复用已有终端与工作区状态，不重复读取
- 连续快速切换时，仅最后一次切换结果生效，较早返回的异步响应必须丢弃
- 搜索框内支持 `↑ / ↓` 切换高亮项，`Enter` 直接激活当前高亮项
- `⌘ + ←` 选择上一个最近项目，`⌘ + →` 选择下一个最近项目
- 若焦点位于输入框、文本域或可编辑元素中，不拦截方向键

## 实现边界

- 本次不拆分“已注册项目”和“已打开 Tab”两套模型
- 顶部 Tab 保持 store 中的固定顺序；最近项目菜单单独使用最近激活顺序
- 顶部 Tab 的固定顺序由前端本地持久化恢复
- 本次不改后端项目排序逻辑，只在前端维护最近项目记录
